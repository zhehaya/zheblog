# T574434 入穿入烂

## 题目描述

给定长度为 $n$ 的序列 $A_1,A_2,\cdots,A_n$，问能否找到两个非负整数 $B$ 和 $C$，使得：

$$
(A_1+B)\oplus C<(A_2+B)\oplus C<\cdots<(A_n+B)\oplus C
$$

其中 $\oplus$ 是按位异或运算。

## 输入格式

第一行两个整数 $T,id$，分别表示数据组数和测试点编号。

每组数据的第一行为一个整数 $n$，表示序列长度。

第二行 $n$ 个整数 $A_1,A_2,\cdots,A_n$。

## 输出格式

对于每组数据，若能找到符合要求的 $B$ 和 $C$，则输出一行一个字符串 `YES`，否则输出一行一个字符串 `NO`。

## 输入输出样例 #1

### 输入 #1

```
4 1
3
1 2 1
3
1 2 3
3
3 2 1
4
1 63 2 64
```

### 输出 #1

```
NO
YES
YES
NO
```

## 说明/提示

对于 $100\%$ 的数据，$1\le T\le 10^4$，$2\le n,\sum n\le 2\times 10^5$，$0\le A_i<2^{30}$。

| 测试点编号 |     $n\le$     |  $\sum n\le$   | $A_i <$  | 特殊性质 |
| :--------: | :------------: | :------------: | :------: | :------: |
|   $1,2$    |      $10$      |     $100$      |   $32$   |          |
|   $3,4$    |     $100$      |     $10^3$     | $2^{10}$ |          |
|   $5,6$    |    $2^{10}$    | $2\times 10^5$ | $2^{10}$ |    A     |
|   $7,8$    | $2\times 10^5$ | $2\times 10^5$ | $2^{30}$ |    A     |
|   $9,10$   | $2\times 10^5$ | $2\times 10^5$ | $2^{30}$ |          |

特殊性质 A：若存在符合条件的 $B,C$，则保证存在满足 $B=0$ 的符合条件的 $B,C$。

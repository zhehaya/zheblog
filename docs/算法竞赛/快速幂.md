### 递归写法

```cpp
long long fast_pow(long long a,long long k){
    if(k==0) return 1;
    long long res=fast_pow(a,k>>1)%p;
    if(k%2)
        return ((res*res)%p*a)%p;
    else 
        return (res*res)%p;
}
```

### 非递归写法

long long fast_pow(long long a,long long k)
